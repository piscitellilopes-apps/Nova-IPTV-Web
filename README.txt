NOVA IPTV - Eigenständiger Webplayer inspiriert von den üblichen Funktionen von IPTV Smarters Pro.
Dateien: index.html und manifest.webmanifest. Im GitHub-Repository ersetzen/hochladen.
Funktionen: M3U-Link, lokaler Dateiimport, 2 Profile, Live-TV, Kategorien, Suche, Favoriten, MPEG-TS via mpegts.js, HLS via hls.js, optionale lokale Playlist-Speicherung.
WICHTIG: Browser blockieren HTTPS->HTTP (Mixed Content) und CORS. Diese Web-App kann diese Sperren nicht umgehen. Kein IPTV-Dienst oder Stream im Paket enthalten. Keine Zugangsdaten in GitHub speichern.
