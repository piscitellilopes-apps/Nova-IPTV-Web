# Nova IPTV Web – Prototyp

Statische Website für GitHub Pages. Dateien `index.html` und `manifest.webmanifest` in ein separates Repository hochladen. Unter Settings → Pages → Deploy from a branch → main / (root) aktivieren.

Funktionen: zwei lokal gespeicherte M3U-URLs, Senderliste, Suche, HLS-Player via hls.js. Noch keine EPG-, Catch-up-, VOD-, Serien- oder Favoritenfunktionen. HTTPS und CORS des IPTV-Anbieters sind erforderlich. URLs mit Zugangsdaten werden lokal im Browser gespeichert und können im Browser-Verlauf, Netzwerk oder Geräte-Backups sichtbar werden. Keine IPTV-Zugangsdaten im öffentlichen GitHub-Repository hinterlegen.
